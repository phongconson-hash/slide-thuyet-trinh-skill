# Cài skill "Slide thuyết trình kiểu Phong Menly"

## Bạn cần có

- Claude Code (bản máy tính hoặc trong VS Code).

## Cài đặt: dán một câu vào Claude Code

```
Cài skill từ https://github.com/phongconson-hash/slide-thuyet-trinh-skill vào thư mục ~/.claude/skills/slide-thuyet-trinh, rồi kiểm tra có file SKILL.md là xong.
```

Claude sẽ tự tải về và cài. Khởi động lại Claude Code sau khi cài.

## Dùng thử

```
Làm slide thuyết trình cho buổi học hôm nay từ nội dung này: …
```

Gửi kèm nội dung (bài học, ghi chú, link video) và ảnh của bạn. Claude sẽ dựng slide theo phong cách trắng – đen – vàng chanh, mỗi slide một hình vẽ theo đúng nội dung.

## Cập nhật bản mới

```
Cập nhật skill slide-thuyet-trinh trong ~/.claude/skills bằng bản mới nhất trên GitHub.
```

## Gặp lỗi

- **Không thấy trang slide**: tài khoản Claude của bạn cần có tính năng Artifact (Slides). Nếu chưa có, hãy yêu cầu Claude xuất ra file HTML hoặc PPTX.
